Coverage summary: Phase 0 is implemented. Phase 1 is partially implemented.
Phase 2 has partial asset-PDA, secondary async lifecycle, and secondary
position-ledger slices with property coverage for secondary position-ledger
conservation. Phase 3 has an active venue-approved `withdraw_assets` gate and a
constrained venue-position stub with primary and secondary per-asset manager
rolling buckets, but no arbitrary venue CPI boundary.
Phase 4 includes tranche-scoped request binding, request bounds,
junior-ratio guards, waterfall accounting, and lane-local FIFO queue counters,
but not tranche-aware fees. Phase 5 has a primary-asset instant-settlement slice
with per-transaction threshold bounds and per-user rolling buckets. Vault-level
protocol fee splits are implemented for the currently implemented fee sources,
with singleton program-level recipient routing. Program-wide protocol-fee bps
overrides and richer governance remain future work. Remaining
Phase 2-6 PRD requirements are future work unless specifically marked done or
partial.
